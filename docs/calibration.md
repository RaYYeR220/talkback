# Simulator calibration

500 simulated matches between random pairs of the 20 fictional clubs, compared with public per-match averages for a top European league (both teams combined). The engine is never fitted to any real match data; only these aggregate levels were used as tuning targets.

| Statistic | Simulated (mean ± sd) | Public average | Accepted range |
|---|---|---|---|
| Goals | 3.10 ± 2.12 | 2.80 | 2.3–3.3 |
| Shots | 26.4 ± 8.6 | 25.0 | 20–30 |
| Shots on target share | 0.32 ± 0.10 | 0.34 | 0.28–0.42 |
| Passes | 1077.5 ± 101.2 | 950.0 | 750–1100 |
| Pass completion | 0.79 ± 0.02 | 0.82 | 0.76–0.87 |
| PPDA (per team) | 8.6 ± 1.4 | 11.0 | 7–15 |
| Fouls | 16.1 ± 5.3 | 21.0 | 15–26 |
| Corners | 9.3 ± 3.5 | 10.0 | 7–13 |
| Yellow cards | 2.93 ± 1.70 | 3.60 | 2.5–5 |
| Distance per outfield starter (km) | 10.0 ± 0.5 | 10.5 | 9.0–12.0 |

Other per-match means: throw ins 17.2, goal kicks 13.7, penalties 0.3, pressures 656.4, tackles 64.1.

# EBU OGraf v1 specification files

Unmodified copies of the normative OGraf v1 files from [ebu/ograf](https://github.com/ebu/ograf)
(`v1/specification/`, branch `main`, fetched 2026-10-27). The folder layout matches upstream so
the relative `$ref`s in `open-api/server-api.yaml` resolve to the local JSON schemas.

- `open-api/server-api.yaml` — OGraf Server API (OpenAPI 3.0.3)
- `json-schemas/graphics/schema.json` — Graphic manifest schema, with `lib/` and `gdd/` dependencies
